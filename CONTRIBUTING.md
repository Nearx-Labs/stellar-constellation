# Contributing to Stellar Developer Links

Thank you for your interest in contributing! This project aims to be the most comprehensive collection of Stellar developer resources.

## How to Add a Link

1. **Fork** this repository
2. **Add** your link to the appropriate category in `README.md`
3. **Follow** the format: `| [Name](url) | Brief description |`
4. **Submit** a pull request

## Link Format

```markdown
| [Link Name](https://example.com) | Short, clear description of the resource |
```

## Quality Guidelines

- ✅ Links must be **working** and **relevant** to Stellar development
- ✅ Prefer **official** or **well-maintained** community resources
- ✅ Include a **clear, concise** description (max 60 characters)
- ✅ One link per row
- ❌ No duplicate links
- ❌ No affiliate or referral links
- ❌ No broken links

## Reporting Issues

If you find a broken link or have a suggestion, please [open an issue](../../issues) with:

- The link URL
- The category it belongs to
- A brief description

## Code of Conduct

Be respectful and constructive. We're all here to build the Stellar ecosystem together!
